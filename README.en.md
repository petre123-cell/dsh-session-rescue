# dsh-session-rescue

DSH crashed but your session file survived — rescue the conversation inside it.

Frame-by-frame decoder for DeepSeek Harness `session.v4.jsonl.zstd`. Zero dependencies, works offline, exports user messages to Markdown. Requires Node ≥ 22.15 (built-in zstd).

Full docs in Chinese: [README.md](README.md) · Crash casebook: [docs/casebook.md](docs/casebook.md) · First-aid checklist (bilingual): [docs/FIRST-AID-CHECKLIST.md](docs/FIRST-AID-CHECKLIST.md)

**Unofficial community tool** — not affiliated with or endorsed by DeepSeek. Provided as-is, see [LICENSE](LICENSE). The tool reads local files only; exported Markdown contains private conversations — keep it safe.
